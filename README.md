# Master PokéMart

A small Pokémon catalog and shopping cart built as a portfolio project. Browse the PokéAPI catalog, filter by name, type, and region, choose shiny Pokémon, and add items to the cart.

## Stack

- React 18 and TypeScript
- Vite
- Tailwind CSS 4 and shadcn/ui
- Redux for filters and cart state
- PokéAPI

## Requirements

- Node.js 22
- npm

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

The app fetches catalog and Pokémon data from [PokéAPI](https://pokeapi.co/).
